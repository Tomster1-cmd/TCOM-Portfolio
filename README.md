# Tom Trinh — CST Portfolio

A responsive, static portfolio website built with HTML, CSS, and a small amount of JavaScript. It can be published for free using GitHub Pages.

## Files
- `index.html` — portfolio content and sections
- `styles.css` — responsive layout and visual styling
- `script.js` — mobile navigation menu
- `resume.pdf` — add your reviewed resume PDF here before publishing

## Before publishing
1. Search `index.html` for `ADD_YOUR_EMAIL_HERE`, `ADD_YOUR_GITHUB_URL_HERE`, and `ADD_YOUR_LINKEDIN_URL_HERE`, and replace or remove the placeholders.
2. Add `resume.pdf` (or change the resume link to match your filename).
3. Add genuine screenshots, demo URLs, and repository links for each project. Current project illustrations are CSS mockups, not screenshots of working applications.
4. Review each STAR reflection. Update project statuses, your exact contributions, and results so every statement is accurate. Do not publish confidential client information.
5. Confirm the education completion date and work dates are correct.
6. Test all links on desktop and mobile.

## Publish free with GitHub Pages
1. Create a new public GitHub repository, for example `tom-trinh-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, this README, and your resume/assets.
3. Open the repository's **Settings → Pages**.
4. Under the build/deployment settings, select **Deploy from a branch**, choose `main` and the `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish and open the generated URL. Test it in a private/incognito window before submitting it to Brightspace.

## Important
The assignment rubric asks for a published, accessible website; contact information; a resume; at least three projects with artifacts and STAR explanations; and authorship plus last-updated information. This starter site contains draft content and placeholder links. Complete the checklist above before submitting.
