STAR reflection

02 / Mobile development Course project

Unit Converter App

A simple Android application that allows users to convert values between different units. Users can select a conversion type from a dropdown menu, enter a value, and calculate the result.

STAR reflection

Situation — Our team worked on creating a simple Android application that could convert values between different units.

Task — The goal was to develop a mobile application that allowed users to select a conversion type and enter a value.

Action — Our team used Android Studio, Kotlin, and XML to develop the application. We included a dropdown spinner to select conversion types, along with buttons to calculate the result and clear the calculator.

Result — I produced Figma interface designs that gave our team a visual reference for the Unit Converter application and helped establish how users would interact with its features.

Project Artifact

I created the mobile interface designs using Figma. The designs demonstrate the planned layout and user experience of the Unit Converter application.
